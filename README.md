
# Diabetes Prediction Using Machine Learning

This project predicts whether a person is diabetic or not using machine learning techniques. It uses the PIMA Indians Diabetes dataset and a Support Vector Machine (SVM) classifier for prediction.

---

## 📌 Project Features
- Data cleaning and missing value handling
- Feature scaling using StandardScaler
- Train-test split
- Model training using SVM (linear kernel)
- Accuracy evaluation
- Predictive system for new input data

---

## 📊 Dataset
The dataset contains 768 rows and 9 columns:
- 8 medical features
- 1 target column (`Outcome`)

`Outcome = 1` → Diabetic  
`Outcome = 0` → Non-diabetic
